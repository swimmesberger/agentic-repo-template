# Research notes

Notes that summarise outside material for this project: documentation, articles, an investigation by the `research` skill. One file per question, named `YYYY-MM-DD-topic.md`, with `type: Research note`, the URLs it rests on under `sources:` in the frontmatter or a `Sources` heading, and an entry in [../index.md](../index.md). A research note is secondary: when it disagrees with its sources, the sources win. Rules in [../guide.md](../guide.md).
